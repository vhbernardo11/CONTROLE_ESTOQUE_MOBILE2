# Armazém POS — pacote completo

Branch criada para registrar o projeto do sistema de restaurante com 27 mesas.

## Escopo implementado no pacote entregue

- Cardápio web por QR Code, sem aplicativo.
- 27 mesas com token individual.
- Pedidos em tempo real.
- Roteamento por item para Churrasqueira, Cozinha e Bar.
- KDS por praça e tela consolidada de Expedição.
- Gestão de salão, cardápio, disponibilidade, caixa, estoque e relatórios.
- Chamadas de atendente e pedido de conta.
- Banco PostgreSQL/Supabase com RLS, autenticação, funções seguras e seed de 115 produtos.
- Gerente IA opcional com OpenAI no servidor.

O pacote-fonte, a versão pronta para publicação, o HTML único e as migrações SQL foram gerados e entregues na conversa. Esta branch não foi mesclada ao sistema de estoque existente para evitar alterar o projeto principal.
